# AI-Based Personalized Career Guidance System for Students

An AI-based web application that helps students identify suitable career paths based on their interests, skills, academic performance, and preferences.

## 📌 Project Overview

Choosing the right career can be challenging for students due to limited awareness and lack of personalized guidance.

This system analyzes student profile and assessment responses using a Python-based recommendation algorithm and provides:

- Personalized career recommendations
- Career match scores
- Skill gap analysis
- Career-wise learning roadmap
- Student profile management
- Contact and feedback facility

## 🎯 Objectives

- To provide personalized career recommendations for students.
- To analyze students' interests, skills, and academic profile.
- To identify skill gaps for selected career paths.
- To provide personalized learning roadmaps.
- To help students make informed career decisions.
